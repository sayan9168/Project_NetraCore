# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 5.x (Court-Ready) | ✅ |
| < 5.0 | ❌ |

## Reporting a Vulnerability

Project Netra-Core processes law-enforcement-grade forensic data; security is paramount.

- **Report privately** to: `security@netracore.example` (or via GitHub Private Vulnerability Reporting).
- **Do NOT** open public issues for security vulnerabilities.
- Include: description, reproduction steps, impact assessment, and affected component.

## Disclosure Policy

1. Acknowledgment within **48 hours**.
2. Coordinated fix and patch release within **30 days** for critical issues.
3. Public advisory published after patch availability.

## Out of Scope

- Attacks requiring physical access to the evidence vault master key.
- Social engineering of authorized operators.
- Denial-of-service against the local edge node.
